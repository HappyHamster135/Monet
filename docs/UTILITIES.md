# Monet Utilities on 0.9.8-9

Open **Monet Utilities** from the application menu. Type in the search field to find a tool. Use the arrow keys to select one while you type, then press Enter. Press **Super+Alt+Space** to open the tool search with your favorites. Type a name such as “volume mixer” or “scratchpad”, then press Enter to use it. The Utilities results also appear in the Home Bar and in desktop search (**Super+R**). Type **tools** to list favorites. The search provider respects hidden tools. The gear lets you hide tools and choose favorites. **Ctrl+K** returns to search from any tool. The launcher's right-click menu also opens the shelf, scratchpad and favorites wheel or switches audio outputs.

Hold **Alt** and press **Tab** to switch windows. Keep Alt down and type part of a title or application name to narrow the list. Tab and Shift+Tab cycle through matches. Release Alt or press Enter to activate the selection, or press Esc to return. In **Settings → Mouse & Keyboard → Window switcher**, choose live previews or a compact list of icons and titles. You can include every window, one window per app or only the active app, and choose which displays contribute windows.

Press **Super+R** to open the **Command Bar** anywhere. Inside the notch, click the search button or press **Ctrl+K** to search in place. **Escape** or the back arrow returns to the page you were using. Search for an app, window or file, calculate, or convert units. Type **snippet:** and a name, typing shortcut or phrase to find saved text. Type **clip:** and a few words to find text you copied earlier, or **emoji:** and a name such as “rocket”. The arrow keys select a result. Enter copies the full text or emoji, ready to paste back in your app. These three searches also work after the **tools** prefix in **Super+Alt+Space**. Hiding Text snippets, Clipboard history or Find an emoji in Utilities removes its search results.

You can calculate with measurements in either Command Bar. Type `100 km / 2 h to km/h` for 50 km/h, or `5 ft 11 in in cm` for 180.34 cm. Press **Enter** to copy the value with its unit. Use `ans` in your next calculation, such as `ans / 2`. Both launchers share the last result marked **Copy result and use it as ans** during this desktop session. To use this action on a simple conversion, start with an equals sign, such as `=10 km in miles`.

To convert a color, type an expression such as `#369 to rgb` or `rgba(51, 102, 153, 0.5) to hex` in the Command Bar. The result shows a swatch. Press Enter to copy the value, then paste it into your app. HEX, RGB, HSL and SwiftUI support opacity. Colors in `clip:` search results also show a swatch.

To run a command from the window you were using, open the Command Bar and type **menu:** followed by a command or menu name. For example, in an editor with a Save As command, type `menu: save as`. Each result shows its menu path and the shortcut supplied by the app. Press Enter to run the selected command in that window. This works with apps that expose a desktop menu or an accessible menu bar.

In **Utilities → Saved scripts**, choose **Add script…**, name the script and browse to an executable file. Open the Command Bar and type `script: name` followed by any text to pass to it. The script runs in its own folder and receives that text as one argument. Enter copies its text output. **Require text after the script name** helps with scripts that need an input. For scripts that can run repeatedly, **Run while typing to preview the output** shows the answer in search. Enter copies the displayed answer. Previews time out after 15 seconds. Scripts started with Enter can finish longer tasks. The Command Bar copies up to 64 KiB of text output. Removing a script from the list keeps the file on disk.

Press **Super+Alt+U** for the **Quick Panel**. Click a favorite, or use the arrow keys and Enter. Select **Edit favorites…** to add or remove a tool. Drag a row or use the arrow buttons to change the order. The first eight favorites appear in the built-in wheel and at the top of tool search. Esc returns from editing, then closes the panel. You can also open it from the Utilities launcher’s right-click menu.

Press **Super+Alt+W** to open the favorites wheel at the pointer. Click a sector, or move with the arrow keys and press Enter. The center shows the full name of the highlighted action. Open a submenu with one click. Click its center or press Esc to go back. At the top level, click the center to switch wheels or choose **Customize wheels…**. The shortcut opens your last selected wheel. In **Utilities → Customize wheels**, create named wheels for tools, installed apps, files, folders, web links and desktop shortcuts. Drag items or use the move buttons to arrange up to eight entries per menu. The built-in wheel follows Quick Panel favorites. For a named wheel, open **Wheel options → Keyboard shortcut…**, record a combination and select **Save**. It opens that wheel directly, including when Utilities is closed. Super+Alt+W keeps its own selection. To release a shortcut, clear it in the same dialog and save.

**Shortcut behavior** applies to all wheels. With **Tap or hold**, tap the shortcut to leave the wheel open, or keep the modifier keys held, point at an item and release to choose it. Returning to the center lets you keep browsing. **Hold to choose** closes the wheel when you release without choosing. **Click to choose** keeps it open for a click or keyboard selection. Shortcuts without modifier keys and the application-menu action always open a wheel you can click.

In **Edit favorites…**, you can pin **Switch light or dark appearance**, **Follow automatic appearance**, **Toggle keyboard backlight**, **Lock screen**, **Turn off displays**, or **Empty Trash…**. You can also run them from tool search. Switching appearance picks Mist or Smoke in Settings. **Follow automatic appearance** restores The Hours. The keyboard backlight returns to its previous level when you turn it back on. **Empty Trash…** asks for confirmation before deleting anything.

Open **Utilities → Choose wallpaper** to browse included backgrounds or add your own pictures and folders from **Collection**. Select a thumbnail and choose **Apply wallpaper**. Clear **Apply to all displays** to change only the screen containing the gallery. Removing a picture or folder from the collection keeps its files on disk. **Light and wallpaper settings** opens Monet’s time-of-day options.

Open **Utilities → Rename shortcut in Files** to edit the keys for the selected file or folder. Files opens its shortcut editor at **Rename** when its search field is available. Select the shortcut or alternate shortcut, record your keys and choose **OK**. Files checks for conflicts. The default is **F2**.

For an individual monitor, open **Settings → Display**. Each screen that reports brightness has its own slider. Under **Display power**, choose **Sleep display** or **Wake display** for a supported output. Quick Settings shows a monitor selector when several screens have brightness controls.

In **Customize Home Bar**, turn off **Show running timers in the closed notch** to keep music and other activity visible during a countdown or focus session. Open **Time** to check, pause or resume it. When a timer finishes, click its reading to open **Time**, then choose **Dismiss** or start another timer. Between focus rounds, the notch shows when the next break or session is ready.

Open **Time → Keep awake** in the notch. Choose **30 min**, **1 hour**, **Until off**, or **End at…** to choose a local time today or tomorrow. A manual session keeps the screen on and delays automatic locking and sleep. The closed notch shows the minutes left. Click the reading to change or stop the timer. A timer survives a Keep awake service restart during the same login and keeps its original end time. Signing out ends the manual session. Stopping a manual timer leaves any matching automatic rule running. You can turn the reading off in **Customize Home Bar → Show Keep awake in the closed notch** and still use the Time controls.

Open **Utilities → Keep awake** or **Settings → Power & Sleep → Automatic Keep awake rules**. Turn on **Use automatic rules**, choose power, an external display or applications, and select **Apply changes**. Choose **Any selected condition** or **All selected conditions**. For the application condition, any one of your chosen apps can satisfy it. Under **Connected to power**, **Wait for power to reconnect** keeps an active power rule through a charger interruption of up to 60 seconds. The default is **No delay**. A match keeps the PC from sleeping automatically. Its screen can still turn off and lock. Select **Also keep the screen on** for presentations. This also delays automatic locking. Minimized windows count, and an app running in a desktop application service or scope can continue to count from the tray. When the selected conditions no longer match, the PC returns to its usual sleep settings. A manual timer keeps its own deadline. The lid uses the action you chose in Power & Sleep.

In **Utilities → Customize**, clear **Show** to hide a tool from the catalogue and its notch controls on every display. Showing it again brings back its saved content and its place in your tab order. Hiding **Watch a window** ends any window preview pinned to the notch.

In **Customize Home Bar → Top-center notch**, select **Compact** or **Wide**. The notch belongs to the screen containing the bar you customized. Moving the Home Bar leaves the notch at the top. Select **Edit notch tabs** to show, hide or reorder Music, Activity, Time, Calendar, Notes, Camera and Clipboard. In the open notch, **Ctrl+Tab** moves to the next visible tab in your chosen order. **Ctrl+Shift+Tab** moves back. **Escape** or **Alt+Left** returns from the file shelf, mixer, downloads, notification details or agenda to the page you came from. Press **Escape** on a main tab to return to your app. If you hide every tab, clicking the notch opens the file shelf. Utilities is available below it. A running timer keeps its deadline when its tab is hidden. Select **Off** to remove the notch. Your Home Bar remembers its tabs and options for the next time you enable it. Music levels, notification previews, the companion and low accessory battery alerts each have a separate control.

- Enable **Show notch companion** and open **Customize companion** to preview a soft face or a robot, choose its shape and color, and put it on either side of the notch. Set how often it visits, hide it between visits, or turn off reactions to music, timers, power and files. **Say hello** previews its greeting. The companion follows your desktop animation setting.
- Click the notch to open Music, Activity, Time, Calendar or Notes. Scroll down over the notch to open it. Scroll up over the notch, song title or album art to close it. Swipe left over those surfaces for the next track or right for the previous track when your player supports it. One continuous swipe changes one track. Turn these gestures off in **Customize Home Bar → Top-center notch**.
- Enable **Clipboard** in **Edit notch tabs** to browse your desktop clipboard history. Type to filter, then click an entry or press Enter to copy it again. Paste into your app with Ctrl+V. Text, images and copied files keep their original formats. You can also star entries or remove them from history. When the tabs need more room, **All tabs** lists them by name.
- Enable **Camera** in **Edit notch tabs**, open that tab and select **Start camera**. Choose a camera from the list if several are connected. Switching tabs, closing the notch or locking the screen ends the preview. For a floating preview, open **Camera mirror** from Utilities.
- In **Music**, open **Playback source** when two players are available. Choose a player to keep its song, transport controls, lyrics and queue together as you switch apps. **Automatic** follows the desktop’s active player. If you enable music levels in Customize Home Bar, the bars follow the selected app on its current output. They stay still when the app is silent or its playback stream cannot be identified. Drag the timeline to seek, or focus it and use the arrow keys to move five seconds. Players that support shuffle or repeat show those controls beside Play.
- **Lyrics** follows playback when the player shares timed words or a local song has a matching `.lrc` file. Select a line to seek in a supported player. **Up next** shows the next tracks from players that share their queue.
- Open **Music → Mixer** to adjust an app’s volume or mute it. An app with more than one playing stream has one row. Its **⋯ → Play through** menu lets you send it to a different output while other apps keep playing where they are. Pin an app to keep its row when playback stops. Drag an app’s name or choose **Move up** or **Move down** to reorder it within its group. Settings → Sound and the Home Bar sound popup share these controls and preferences.
- Drop files, folders, web links or selected text on the notch to open **File shelf**. Drag an item into another app, or select several and drag them together. Editors receive mixed selections as text in shelf order. In Utilities, you can also paste into the shelf, copy a selection or open a text entry to read it in full. **Open shelf in Utilities** opens the same list in a separate window. Removing an entry from the shelf keeps the original file.
- In **Activity → Notifications**, choose a message to read it, open the sender’s action, reply when supported, or dismiss it from desktop history. **Clear notifications…** asks for confirmation and keeps messages that arrive or change while you decide. For five-second previews on the closed notch, enable **Preview notifications in the notch** in Customize Home Bar. Click a preview to read that message. Previews respect the sender’s popup preference, Do Not Disturb and the screen lock.
- Open **Activity → Downloads** for the twelve most recent files in the watched folder. Partial downloads are labeled. Finished files have **Show in Files** and **Add to file shelf** actions. Transfers that report progress to KDE can show it here. **Folder…** lets you choose a different location or return to your Downloads folder.
- In **Time**, use **Start** for a countdown or **Focus** for quiet time. Both can pause and resume. **Focus options** sets the number of sessions, the break lengths and how often a long break is offered. Start each break or next session when you are ready. Pausing, cancelling or finishing a focus interval restores your previous notification setting. The stopwatch and countdown keep their state when the popup closes. Calendar uses the same day notes as the Monet clock.
- In **Notes**, choose a pad or create one with **New pad**. Type directly in the notch, or select **Open floating pad** to keep the note above another app. **Utilities → Scratchpad → Pad options** lets you rename a pad, preview Markdown, export a copy, or delete it. Your previous scratchpad becomes the first pad. If two editors change the same text at once, both versions are saved.
- In **Calendar → Upcoming appointments**, browse two weeks at a time. **Calendars…** lets you link a local iCalendar (.ics) file or subscribe with an HTTPS or webcal link. File edits appear when you reopen or refresh the agenda. Subscriptions keep their last successful copy for offline use. Remove a calendar here to clear its cached copy and keep the original.
- In **Activity → Watch**, choose a window in the desktop sharing picker. Drag over the part you want to follow and select **Show in notch**. Click the notch to see the live region. **Edit region and alerts** lets you change the selection, watch for a phrase, or get one alert when the picture changes or settles. **Stop watching** ends sharing. You can also use Watch as a separate Utilities window.
- In **Settings → Sound → Preferred output order**, choose **Manage…**, add your devices, put the first choice at the top and select **Apply**. Disconnected devices keep their place. A manual output selection lasts until the next connection change. Turn off **Switch outputs automatically** to keep the list for later. The launcher’s **Cycle sound output** action switches directly and names the output that took over.
- In **Settings → Sound → Media keys**, uncheck a browser or player to give other apps the playback keys. You can still control it directly from the app or notch. With no eligible player open, Play does nothing by default. Choose an app in **Play key when no player is available** to have Play open it and request playback.
- Open **Window focus and click behavior** in Utilities or **Settings → Mouse & Keyboard → Window focus**. Choose **Click** or **Hover** to switch windows. With **Use first click**, clicking a button in an inactive window also presses it. **Focus only** selects the window first. Hover delay controls how long the pointer must rest on a window.
- In **Settings → Mouse & Keyboard → Touchpad clicks**, choose a connected touchpad. **Physical click** switches between button areas and finger count on supported clickpads. **Two-finger tap** chooses the secondary or middle button. A three-finger tap uses the other button on hardware that supports it. Expand **Test clicks** to see the events your apps receive.
- If a single mouse click sometimes counts twice, open **Settings → Mouse & Keyboard → Extra click filter**. Choose the affected mouse and buttons, then click in the test box. The default interval is 25 milliseconds. Raise it only as far as needed so intentional double-clicks still register.
- In **Settings → Mouse & Keyboard → Mouse wheel scrolling**, choose **Fixed distance** for an immediate step or **Smooth** for a glide. Set the distance per step and optionally choose a modifier for sideways scrolling. **System default** uses the application’s usual scrolling. Older apps can round movement to whole steps. Under **Use standard mouse controls in**, choose games or other apps that should receive their original clicks and wheel events. The same application list is available in **Extra click filter**.
- In **Settings → Bluetooth**, enable **Turn Bluetooth off during sleep** to disconnect accessories when the computer sleeps. **Restore Bluetooth on wake** turns the same adapters back on and reconnects previously connected mice and keyboards. Switch it off to leave Bluetooth off after waking.
- To save a copied picture, right-click a folder or an empty area in Files and choose **Paste Image as PNG…**. Give it a name and press Enter. This also works when the clipboard includes a caption or link alongside the image. Ctrl+Z undoes the paste.
- Choose **Read text or a QR code from the screen**, then drag across the area you want. From search or a favorite, the result goes straight to your clipboard. From the Utilities catalog you can also edit the result and select **Copy**. Esc cancels the selection.
- Select **Pick a screen color** in Utilities and click a pixel. The result shows its swatch and text. **Copy colors as** sets the format for future picks, including those launched from search, the Quick Panel and the favorites wheel. Esc cancels a pick.
- Open **Compress media** and drop one or more photos, videos or animations. Automatic saves still pictures as WebP, animations as GIF and videos as MP4. You can also choose JPEG, PNG, HEIC on supported systems, or a one-page PDF per file. **Longest edge** resizes proportionally. For still copies, **Picture options…** also lets you set the width, height or exact frame and choose padding, cropping or stretching. Use its Watermark tab for text or a logo, then preview the placement. These choices apply to pictures in the batch. For an attachment limit, set **Maximum file size** in MB. A compatible photo, GIF or MP4 that already fits can be copied at its original quality. Save a single copy under a name you choose, or choose a folder for a batch. The list shows original and saved sizes. Cancel stops the current file and keeps finished copies. **Show in Files** selects a saved copy.
- In **Compress media → Export options**, choose **Web picture**, **Social picture** or **PDF handout**, or **Save as new preset…** to reuse your own settings across sessions. You can update, rename or delete your selected preset from the same menu. The Web and Social presets remove camera and location tags. **Picture options → File** also lets you set a background or keep the original modification date.
- Choose **Export options → File names…** to preview a pattern against the queue. For example, `{index:03}-{name}-{width}x{height}` produces names such as `001-Poster-800x600.webp`. Insert fields for date, time or format at the cursor. Numbers follow the queue order and dates use the local time at the start of the batch. Monet adds the extension and numbers copies when a name is taken. For one file, **Save copy…** lets you choose the exact name. **Export options → Save to folder…** generates it from the finished copy.
- Open **Screen recorder and editor** in Utilities. Choose **Record…** to select a region, window or screen. The same menu lets you include system sound or your microphone. These choices are shared with Spectacle. Enable **Zoom to clicks** to follow primary clicks inside the selected capture. Nearby repeated clicks share a zoom. The editor keeps up to 256 click groups per take. You can adjust, remove or restore these zooms in the editor, including after reopening the take. Click the recording indicator in the tray to finish and open the take. **Open recording…** edits an existing video. Set the start and end, draw a crop, choose playback speed or mute audio. Under **Overlays**, add a caption, place a local image or blur an area. Drag the box to move it and its corner to resize it. Set when it appears and disappears. Use **Bring forward** or **Send backward** to change which overlay is on top. Select an existing overlay from the menu to edit or remove it. Use **Zooms → Add zoom at playhead…** to bring a detail closer. Choose the focus point in the picture, set the magnification and adjust the start and end. The preview eases in and out. Reopen **Zooms** to adjust, remove or undo an edit. **Export copy…** saves a new MP4 or looping GIF.
- In **Listening ports**, search by port, address, protocol, process name, or PID. **Manage process…** shows the owner and its children. Choose a process and select **End process…** or **Force quit…**. Turn on **Include child processes** to act on the displayed branch. **End or restart a process** also finds processes without a listening port. **Restart app…** reopens a recognized desktop app after its original process exits.
- Open **Homebrew packages** to see what you installed, filter dependencies or find updates. In **Find packages**, choose Formulae or Casks, type a name and press Enter. Select a result for details or to install it. **Update Homebrew** refreshes the package catalog. **Update all…** upgrades eligible packages and respects pins. If Monet cannot find a working Homebrew installation, open the setup guide or choose an executable under **Options**.
- In **Text snippets**, save a phrase and choose **Add typing shortcut…**. For example, the word `hi` makes `;hi;` insert that phrase in a supported editor. **Set up typing…** opens the input settings and activates the optional Monet Text Snippets input method. Shortcuts are case-sensitive and follow your active IBus keyboard layout. Password and PIN fields that identify themselves to the input method keep the literal text. You can also copy any snippet directly.
  Open **Variables** to insert the current date, time or clipboard text at the cursor. **Custom date or time…** previews your format and time zone. The values are filled in when you copy the snippet, select it from Command Bar or type its shortcut. For example, `{{datetime-tz(Europe/Stockholm):yyyy-MM-dd HH:mm}}` inserts Stockholm time. If a snippet needs clipboard text and none is available, typing leaves its shortcut in place. Turn off **Expand variables in this snippet** to use the braces as ordinary text.

- In **Cleaning mode**, choose a duration and how your screens should look. **Lock the session** uses the normal lock screen. **Darken displays** and **Keep desktop visible** pause desktop input and return directly to your apps when time runs out. Each display has a **Finish cleaning** button. In these two modes you can also press Esc five times. A real session lock always requires the normal unlock.
- In **Settings → Default Apps → Quit on last window**, choose apps that usually stay open in the background. Monet asks the app to quit after its last window closes. A minimized window or a window on another desktop still counts. For an app without a Quit action, you can opt in to a termination request for its identified background process.
- In **Quit and close protection**, choose **Quit application** for Ctrl+Q or **Close tab or window** for Ctrl+W. Enable either shortcut and choose a hold, a second press, or an extra key to confirm it. You can adjust the timing and include or exclude individual apps. Both protections start off.
- Press **Super+Ctrl+V** in an editable field to paste without formatting. Your next normal paste can still use the original styling. To change the keys, open **Paste as plain text shortcut** in Utilities and search for **Paste as plain text**.
- In **Automatically clear clipboard**, choose a delay after copying, clear on screen lock or sleep, or combine those options. Each new copy restarts the timer. Saved clipboard history and the middle-click selection stay available. All three options start off.
- In **Copied link settings**, turn on **Clean copied links automatically**. Copy a plain web address and paste it in any app. Monet removes common tracking parameters while preserving the remaining query and fragment. You can also use **Clean a copied link** once.
- In **AI session usage → Account limits**, turn on **Show Codex account limits** to see how much of each Codex window is left and its local reset time. Activity in the notch shows the same figures. Choose **Claude Code** in the provider menu and turn on its separate switch to see the five-hour, weekly and model-specific windows reported by Claude Code. The notch can show both accounts. Selecting a row opens that provider. Each signed-in CLI supplies its own figures on demand. Claude Code can return a cached reading. **Refresh** requests a new reading. **Choose Codex CLI…** lets you select a portable installation. Turning the switch off clears the saved reading. In **Session file**, choose a local log or an OpenCode database. This tab and the notch’s Activity overview update as the chosen file changes. Select the session row in the notch to open its details. The reader stops when both views close. **Forget** clears the selection and leaves the file on disk.

  Session totals, individual request counts and reported costs are labeled separately. OpenCode databases can contain multiple sessions, so the row identifies the latest assistant message in the database. Codex, Claude Code and Copilot logs can also show the last recorded turn event. Which figures appear depends on what the agent wrote to the file.

On the bar containing your app icons, open **Customize Home Bar → Behavior**. Choose whether clicking the active window minimizes it, and whether clicking a group cycles through its windows, shows previews, opens the window overview or lists its titles. Select a window by clicking its title or thumbnail in a preview. Choose **Snap layouts** beside the title to place that window in a half, third or quarter of its screen. Escape leaves it where it was. Choose **Middle-click an app icon → Minimize or restore the window or group** to hide or bring back an app’s windows together.

In **Customize Home Bar → Add widgets…**, add **System** to the bar you want to monitor. If the gallery was open before a live update, look under **More widgets → System**. It starts with CPU and memory. Click the readings and select **Choose Home Bar readings** to add, remove or reorder them. Choose numbers, usage bars or both. Available graphics chips and fans appear by device. Battery time shows time to full while charging and time left while discharging when the battery provides an estimate. Move the bar to the side to stack the readings vertically.

Open **Network activity** in Utilities to see live download and upload rates, the last minute of traffic, and traffic totals for each connection. **This session** counts from the first reading in the current login and can be reset. **Since device started** shows the kernel’s counters. Choose a connection to see and copy its local IPv4 or IPv6 addresses. **Open Task Manager** gives access to per-app usage. In **Speed test**, choose **Run speed test** to measure HTTP latency and Internet download and upload speeds using Cloudflare. It uses the system network route and up to 100 MB in each direction. Cancel at any time. Closing or minimizing Utilities ends a running test.

Open **System alerts** in Utilities to choose limits for CPU usage, CPU or battery temperature, disk space and discharging batteries, or to enable memory-pressure warnings. **Refresh readings** shows what this PC reports. Select **Apply changes** to start monitoring. Notifications respect Do Not Disturb. Hiding System alerts in Customize pauses its monitor and showing it again restores your choices. Turning off every alert stops the service.

Open **Fan speeds and supported controllers** for live fan readings. Speed and target RPM appear when the driver reports them. On a PC with a local CoolerControl service, choose a fan and apply a fixed speed, a saved profile or the hardware default. **New curve…** lets you choose a temperature sensor and drag points or enter exact values. Save the curve, then choose **Apply**. Editing an existing curve updates the fans already using it. If the service requires access, enter a CoolerControl access token. Utilities keeps it in memory for the current session.

## Coverage of the reference app

The product reference is [Vorssaint’s feature list](https://vorssaint.com/). Its macOS utilities and Monet’s Linux desktop have different system interfaces. This table records the scope of the local build.

| Area | Available in Monet | Remaining differences |
| --- | --- | --- |
| Windows and taskbar | Searchable Alt+Tab with live previews or an icon list, application and monitor filters, window previews, taskbar interactions, maximize and snap layouts. The title controls follow a stationary pointer after focus changes and stay available as the snap preview fades. Selected apps can quit when their last window closes. | Apps without a Quit action need an identifiable process for optional background termination. |
| Mouse and keyboard | Mouse and keyboard settings, per-touchpad click choices, hover focus and first-click behavior. Mouse wheels have smooth and fixed-distance profiles and a sideways scrolling modifier. Input Remapper provides button, key and modifier mappings. Mouse buttons have an optional per-model extra-click filter. Keyboard bounce and sticky-key settings are available. Quit and close shortcut protection has independent confirmation methods, timing and application lists. | Three-finger click availability depends on the device and its settings. |
| Clipboard and files | Clipboard history, copying as plain text, pasting without formatting with Super+Ctrl+V, manual or automatic link cleanup, reusable snippets with optional typing shortcuts in IBus-compatible editors, pasting clipboard images as PNG, file cut/paste and a customizable rename shortcut in Files, shelf and download folder monitoring. | Typing shortcuts require input-method support from the app. Monet uses Linux app installation formats. |
| Audio, energy and displays | Per-player media key permissions, an optional Play-key launcher, per-app volumes and devices in Monet Sound, automatic output priority, cycle output, microphone mute, timed and conditional keep-awake, optional Bluetooth power and reconnection on wake, per-monitor brightness, screen sleep and wake, and hardware-supported HDR. | Apple XDR brightness is hardware-specific. |
| Desktop tools | Search apps and their menu commands, a floating Quick Panel with editable favorites, wheel, named floating scratchpads with Markdown preview and text export, wallpaper gallery with linked folders and per-display application, camera mirror, color picker, local text/QR recognition, screenshots, screen recording, trimming, cropping, speed, timed captions, image overlays, blur regions, editable timed zooms, automatic zooms from captured clicks and MP4/GIF export, and media compression with saved presets and batch naming. Storage and Apps handle cleanup and removal. Timed cleaning can keep apps visible, darken all displays or lock the session. Searchable listening ports and process trees support quit, force quit and relaunching recognized desktop apps. Homebrew package search, installation, updates and removal work with an existing installation. Task Manager and Updates open on demand. | Presets are local to the account. A watermark logo refers to its file on that computer. |
| Notch | Media playback, synchronized and plain lyrics, live player queues, a per-app mixer with output routing and pinned apps, per-player audio levels, editable scratchpads, calendar, day notes and upcoming appointments from iCalendar files and subscriptions, notification actions and replies, optional short notification previews, timers, accessory levels and low-battery alerts, recent downloads with file actions and native transfer progress, live updates from a selected agent session, opt-in Codex and Claude Code account limits with reset times, live views of selected window regions with change and text alerts, and an optional companion. | OpenCode and Copilot show usage from a selected local session. |
| System monitoring | The System widget puts selected readings on each Home Bar. Task Manager covers CPU, graphics, memory, network and disks. Network activity shows per-interface rates and totals, local IPs and an on-demand speed test. Optional desktop alerts monitor load, pressure, temperatures, writable disk space and battery charge. Utilities shows live fan readings and supports fixed speeds, editable temperature curves and hardware reset through CoolerControl. It also exposes USB devices and power. | Adjustable channels depend on the driver and local controller. The ThinkPad uses firmware cooling with its current kernel settings. |
