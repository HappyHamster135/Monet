Monet now installs from one download: write the installer to a USB stick, boot it, done.

**Start here: [Install Monet](https://github.com/HappyHamster135/Monet/blob/HEAD/docs/INSTALL.md)**

### Downloads

| File | What |
|---|---|
| **Monet-0.2.0-Installer.iso** | **Start here.** Write it to a USB stick and boot from it. Installs Monet next to Windows. |
| Monet-0.2.0-Windows.zip | Only needed if Windows is encrypted with BitLocker |
| Monet-0.2.0-Linux.tar.gz | Only for adding Monet to an existing Bazzite install |

### New in 0.2

- **One-download install.** The Monet installer (about 1 GB) installs the full
  Monet OS next to Windows. It downloads Monet while it installs, so it needs
  internet.
- **Windows sets itself up.** Monet prepares Windows by itself. The first time
  Windows starts, click Yes once, and your PC comes back to Monet with your
  Windows games listed.
- **Monet OS image.** Bazzite (KDE Plasma, NVIDIA drivers for RTX 20-series
  and newer) with Monet built in. It updates weekly.

### From 0.1

- **Play on Windows** from the Windows Games button in the panel.
- **Back to Monet automatically** when you quit the game. Windows hibernates,
  so next time it resumes in seconds.
- Finds **Steam, Epic, and Riot** games. Others can be added by hand.
- Keeps Monet as the default system, even after Windows updates.

### Good to know

- **Preview.** Not tested on real hardware yet. Back up first.
- The installer screens still say Fedora: Monet uses Fedora's installer for now.
- Windows encrypted with BitLocker needs one manual step (see the install guide).
- Between games, Windows is hibernated. Don't change files on the Windows drive from Monet.
