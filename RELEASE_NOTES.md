The first preview of Monet: play Windows games from Linux with one click.

**Start here: [Install Monet](https://github.com/HappyHamster135/Monet/blob/HEAD/docs/INSTALL.md)**

### Downloads

| File | Where | What |
|---|---|---|
| **Monet-0.1.0-Linux.tar.gz** | Bazzite (KDE) | Monet Switch, the Windows Games widget, the Monet look |
| **Monet-0.1.0-Windows.zip** | Windows 11 | Monet Bridge: starts the game, returns to Monet afterwards |

### What's in 0.1

- **Play on Windows.** A Windows Games button in the panel lists your Windows
  games. Press Play and the PC restarts in Windows and starts the game.
- **Back to Monet automatically.** When you quit the game, Windows hibernates
  and the PC returns to Monet. Next time, Windows resumes in seconds.
- **Finds your games.** Steam, Epic Games, and Riot (Valorant, League of
  Legends). Others can be added by hand.
- **Stays in charge of startup.** If a Windows update makes Windows start by
  default, Monet Bridge puts Monet back first.
- **The Monet look.** Impressionist sunrise wallpaper (light and dark) and Monet
  Blue accent.
- **Game Profile for Windows** (optional): full speed while plugged in, Game
  Mode on, fewer ads and tips. Nothing is removed unless you ask.

### Good to know

- **Preview.** Tested in simulation, not on real hardware yet. Back up first.
- Built for **Bazzite with NVIDIA** (RTX 20-series and newer), with Secure Boot on.
- Battle.net, EA and Ubisoft games need to be added by hand for now.
- Between games, Windows is hibernated. Don't change files on the Windows drive from Monet.
